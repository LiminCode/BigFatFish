# 提示词配方

给 AI 视频 / 图片生成工具用的提示词，是「① 提示词 → ② 素材生成链 → ③ 角色包」三步里的
第一步。照着它生成绿幕源视频，再交给 [`tools/asset_pipeline/`](../tools/asset_pipeline/README.md)
处理成桌宠能播的透明动画。

| 文件 | 内容 | 什么时候用 |
|---|---|---|
| [`桌面宠物 10 秒动作提示词.md`](桌面宠物%2010%20秒动作提示词.md) | 一段「通用前缀」（绿幕、人物站位、安全边距、道具「无→有→无」闭环等硬约束）+ 一百多个动作各自的按秒分解。 | 做新动作、给自己的角色做一整套动画。 |
| [`系统通知图标 AI 生成提示词.md`](系统通知图标%20AI%20生成提示词.md) | 同一角色、同一画风的 6 张贴纸风小图标（完成 / 失败 / 截断 / 审批 / 提问 / 测试）。 | 给角色配一套表情图标（通知、头像、气泡配图）。文件名是上游 DSH 插件的约定，本项目不按这些名字读取。 |

## 怎么用

1. **通用前缀每次都带上**。它保证每段视频里人物的大小、位置、首尾帧完全一致——素材链
   后面的「统一站立居中、脚底对齐」只做微调，站位差太多救不回来。
2. **一个动作一段 10 秒视频**：`通用前缀 + 该动作的分解`，再附上角色参考图。上游素材用
   豆包生成，可灵、Runway 等同理。
3. 生成结果按动作名存成 mp4（如 `吃白饭.mp4`），放进 `asset-work/video/`，然后跑素材链。

## 换成自己的角色

配方里写死的是上游角色的外形（蓝发女仆、头顶呆毛、鲸鱼尾巴）。换角色时：

- 把「通用前缀」里点名身体部位的地方（呆毛、鳍饰、裙摆、鲸鱼尾巴）换成你的角色最高 /
  最外 / 最低的部位——那几条约束的目的是不让任何部位出画或贴边。
- 头饰很高的角色，把「头顶约 20%」放宽到 15%（README「素材生成教学」里有说明）。
- 各动作分解里提到尾巴 / 呆毛的句子按角色改写；动作节奏（0–3 / 3–7 / 7–10 秒）保留。
