# 0021 随手记一条一个文件；整理的规矩只有一份，在私有库里

- 状态：已采纳（2026-11-24）
- 相关：[0015](0015-private-repos-are-home.md)、[0018](0018-content-pages-move-to-the-browser.md)、[0020](0020-vault-sync-never-picks-a-side.md)

## 背景

用户要一个随时能记的入口：X 上的帖子、手机截图、书里的一段、临时想法；AI 代为整理，之后每天 / 随机提醒复习。记的地方
有两个：肥鱼（个人简报页顶部的输入框），和手机上的 Claude Code 云端会话（它克隆个人知识库、按根目录
`CLAUDE.md` 办事、直接推送）。原来的「记灵感」把每条追加到同一个文件当天那一节，那个文件从没写过。

## 决定

- **一条一个文件**：肥鱼把随手记原样写进知识库的 `0-Inbox/`（图片放 `0-Inbox/assets/`），不经 AI，立刻推送；从不往已有文件里
  追加。手机和电脑可能同一分钟都在推，各写各的新文件永远不会冲突。
- **整理的规矩只有一份，放在私有库里**（`9-Learning/Notes/README.md`）：手机上的 Claude 当场照它整理；肥鱼以后的整理任务也读它。
  公开仓库里只有「写文件、推送」这一层，用户的分类、口味和复习间隔都不进这里。
- **复习状态写在每条笔记自己的 frontmatter 里**（`review.next / interval / count / lapses`）：哪边复习都改那条笔记，另一边拉一次就知道。
- 「记灵感」并进随手记：同一个输入框，灵感就是一条没有出处的随手记。

## 后果

- 收件、笔记、图片、复习状态全在用户的私有仓库里，硬盘全毁也能恢复（0015）；本机不存这些。
- 改整理规矩不用改肥鱼，也不用发版：改那份 README，两个入口同时生效。代价是规矩和代码分在两个仓库，肥鱼的测试只能用虚构样例守住格式。
- 收件箱平时应该是空的；积了很多条，就是整理（手机或肥鱼）没在跑。
- 还没做的：肥鱼自己的 AI 整理任务、复习提醒和复习页、配置全景上的磁贴与设置组。随手记的推送和知识库同步器还不共用一把锁（路线图 M4c 最后一项）。
