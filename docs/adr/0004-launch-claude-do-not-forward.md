# 0004：外部的 Claude 只一键拉起，不转发对话

日期：2026-10-15

## 背景

肥鱼自己的聊天走个人 key，只有只读工具。用户有时想用功能完整的 Claude Desktop，或 WSL 里另一个账号的 Claude Code。
一个自然的想法是让肥鱼把话转给它们。

## 决定

右键菜单里的「Claude Desktop」「Claude Code（WSL）」只负责把程序拉起来：不传提示词，不传模型，不加配置键。

没有选的路：

- 把肥鱼聊天框里的话转发过去：现有的 WSL 通道只有固定提示词的单向任务，转发要另建一条通路，
  还会让两个账号的内容经肥鱼互通（见 [0003](0003-two-accounts-two-channels.md)）。
- 往交互式 Claude Code 的终端界面里塞字：靠模拟输入，不可靠，也无法确认对方收到了什么。

## 后果

- 两条入口没有状态、没有线程、没有设置，装或卸了程序下一次右键就反映。
- 想要「肥鱼代问」，需要重新做决定并设计一条新的通路，不是在现有入口上加参数。
