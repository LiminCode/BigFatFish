# 0009：记忆蒸馏以条目库为唯一真相，每条都由人审核

日期：2026-10-31

## 背景

记忆蒸馏从 Claude Code 的会话记录里抽出用户说过的话，提炼成长期记忆，写进 `CLAUDE.md`、项目 memory 和知识库。
这些落点里同时有用户手写的内容。要能真的改掉、作废旧记忆，又不能碰手写的部分。

## 决定

- 数据源是 Claude Code 自己落盘的会话记录，不另装采集。抽出的候选只存在本机，不进 git，滚动保留 90 天。
- 模型只产出**提案**（新增 / 改写 / 作废），带原话作证据。没有自动接受：每条由用户在提案页接受、改写、拒绝或跳过。
  拒绝过的标题会回灌给模型，让它别再提。
- 接受的条目进条目库，条目库是唯一真相。`CLAUDE.md` 里的受管块、项目 memory 文件、知识库里的镜像都从它整体渲染。
- 只动自己写的：受管块之外逐字不动，改之前备份。
- 个人侧和公司侧的候选、提案、条目库、模型通道全部分开（见 [0003](0003-two-accounts-two-channels.md)）。

没有选「模型直接改记忆文件」：改错了没有审核点，也分不清哪些是手写的。

## 后果

- 记忆不会在用户不知情时变化，代价是提案要有人去审。
- 指向手写记忆的「作废」提案接受不了，会报错留在待审里。
- 改条目库的格式要同时改三处渲染。
- 备份目录不自动清理。
