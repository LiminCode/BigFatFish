# 0016：看屏幕和拖文件解读整个删掉，不按 0012 只摘入口

日期：2026-11-18

## 背景

路线图 M4 的下一项是把「文件解读、看屏幕」的设置搬到配置全景（[0014](0014-panorama-becomes-the-console.md)）。
用户说这两个功能都不需要，直接去掉，代码也删。

- 「看屏幕」：主动识屏（定时截前台窗口，交给视觉模型，冒一句关怀）和右键菜单「看看屏幕」（截一次屏，问视觉模型）。
- 「拖文件解读」：肥鱼吃完拖进来的文件后，问要不要交给 AI 解读，再冒进度和摘要。

[0012](0012-retire-the-entry-keep-the-code.md) 定过下线时只摘入口、能力代码留着，理由是那批代码和别处交织、拆的风险大。

## 决定

这两个功能连代码一起删，分两个 PR 落地（先文件解读，再看屏幕）：

- 删掉它们独有的模块、设置页、菜单项、配置全景上的磁贴和文案；
- 旧配置里它们的键加载时不读进来，下一次保存就从 `config.json` 里消失；
- `tests/test_retired_features.py` 守着：模块文件不许回来，`pet/` 里不许再 import，键、文案、磁贴都不许回来。

留下的：吃文件的动画和统计（`file_eater` / `sprite_feeding`），以及 `vision.py` 里别处还在用的平台小工具
（前台窗口信息、光标可见性、系统空闲秒数）。

没有沿用 0012：这两个功能自成一块，和别处只连着几个接缝；留着它们，M4 就还得为它们做设置页，用户也明说了删代码。

## 后果

- 想要回这两个功能只能从 git 历史里捞，而且要重新接线、重新做设置。
- 旧配置里的这几个键被丢弃是不可逆的：回滚代码后，用户原来的设置不会回来。
- 0012 仍然适用于和别处交织的功能；能整块拿掉的，按这一条删。
